Interpolation Search Trainer

Decrease-and-conquer search on a sorted array. Trace the algorithm row by row.

How this works
  1. Start with l = 0 and r = n − 1.
  2. While l ≤ r and A[l] ≤ v ≤ A[r], estimate a probe position:
x = l + ⌊ (v − A[l]) × (r − l) / (A[r] − A[l]) ⌋
  1. If A[x] = v → found at index x.
  2. If A[x] < v → search the right part: l = x + 1.
  3. If A[x] > v → search the left part: r = x − 1.
  4. If the loop condition ever fails without finding v → not found.
